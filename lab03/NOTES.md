git diff показывает разницу между двумя состояниями (рабочей папкой, индексом, коммитами). Отвечает на вопрос «что изменилось».

git show показывает один коммит целиком — его метаданные и diff относительно родителя.

git log показывает список коммитов (историю), без diff-а по умолчанию.

git log -S"def" нашёл коммиты, в которых добавлялось или удалялось вхождение строки "def" — то есть когда появлялись/менялись определения функций.

git blame показал построчно, какой коммит и какой автор добавил каждую строку файла — удобно, чтобы найти, когда появилась конкретная строка.
